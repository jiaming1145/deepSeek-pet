# Phase 2 final review — synthesis

Branch reviewed: `phase1-stage..main` (HEAD 16bf16a). Seven lenses (brain, memory-protocol, main-process, renderer-craft, eval-honesty, security, spec-coverage); every finding below survived an independent adversarial verification pass (reproduced by running where marked, otherwise confirmed from the quoted lines). Nothing was refuted. Baseline health: `npx vitest run` 55 files / 611 passed / 2 skipped (gated live tests); `pnpm -r --if-present typecheck` clean on all six projects.

## Verdict

**FIX-THEN-SHIP** — 0 critical / 14 important / 28 minor.

No finding is a security hole, a data-corruption path, or a wrong behaviour on the common happy path: the key never leaves `safeStorage`, every IPC boundary is sender-authenticated and zod-parsed, the prompt-cache prefix is byte-stable, and the shipped evidence is honestly labelled. But fourteen confirmed defects each put a real, reproducible wrong behaviour in front of the user or falsify a gate the eval is supposed to enforce: four silently lose or truncate reply text (malformed tag swallow, tag-only silence, reply-scope tail lint, >2000-char composer), three leave the shell in a wrong visual state (band not re-shown after a visibility edge, chat opened while hidden, unbounded `<|PAUSE|>` parking an empty band), three lose persisted rows on fault or race (assistant-append failure swallows turnDone, quit-mid-reply drops the `[中断]` row, delete-during-trim moves `last_trim_id` past unsummarised turns), one is a timing contract break (hover linger), two make the R8 eval gate weaker than the spec (judge sees sanitized text; A9 zero-flip term missing), and one is a spec-authority behaviour silently narrowed without a tracked ruling (A22). Each has a small, local fix (most are 3–15 lines plus a regression test); none requires redesign. Ship after the important set is fixed and the listed probes are added as tests; the minors can follow in the same PR or be carried as marked.
