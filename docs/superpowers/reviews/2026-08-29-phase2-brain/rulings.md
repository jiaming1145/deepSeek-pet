## R-rulings (E table)

- **R1 — Erasable TypeScript only in `@ds/brain`, `@ds/memory`, `@ds/protocol`.** No parameter properties, no `enum`, no `namespace`, no `import x = require`. Enforce with `"erasableSyntaxOnly": true` in those packages' tsconfig (TS ≥ 5.8; verify installed version, fall back to a `pnpm lint:erasable` grep script if older). `eval/` becomes a workspace package (`eval/package.json`, `"@ds/brain": "workspace:*"`, `"@ds/memory": "workspace:*"`), `eval/run.mjs` stays `.mjs` and imports the packages' `src/index.ts` under Node 24 type stripping. — Keeps brain loadable by plain Node tools; decided before Task 1 so literal code is written once. — Cost if wrong: a `pnpm --filter eval run` failure surfaced in Task 10.
- **R2 — Add `playback:sentenceDone {turnId, seq}` and `playback:turnDone {turnId}` (bubble → main).** Truthful history is **sentence-granular**: on interruption, history keeps exactly the sentences whose `sentenceDone` arrived, plus a `[interrupted]` marker on the assistant row. Spec §3.6's wording is amended by this ruling. — Grapheme-level progress would double IPC rate for a marginal gain. — Cost: history may omit a half-shown sentence.
- **R3 — The bubble gets its own BrowserWindow (`BubbleWindow`).** `frame:false, transparent:true, backgroundColor:'#00000000', alwaysOnTop:'screen-saver', skipTaskbar:true, focusable:false, hasShadow:false, resizable:false, show:false` + `ready-to-show`; sized by content up to 460×320 DIP; positioned by main (pure function `placeBubble(petBounds, bubbleSize, display.workArea, preferredSide)` with flip/shift, padding 16, **never crossing the pet's display work area**), re-placed on pet drag/move, `setIgnoreMouseEvents(true,{forward:true})` except while the pointer is over the bubble DOM (same hover pattern as the pet). The **hint surface** (non-character system hints, addendum C10/X6) is a second layer in the same window. The pet window stays 420×720. — Makes addendum C6/C14 literally true and keeps the pet window click-through logic untouched. — Cost: one more window to show/hide with the pet's visibility state (BubbleWindow follows `VisibilityState.hidden`).
- **R4 — Stream, don't buffer.** Sentences are emitted (`brain:sentence`) the moment they close **and** pass sentence-local lint. Reply-level lint (closing moral/升华, ending 反问, repetition vs recent replies, emoji rate) runs on the tail: a failing **final** sentence is stripped before emission (never painted). Regeneration (≤ 1 per turn, nudge NOT persisted to history) happens only when the **first** sentence fails, because nothing is painted yet; a later sentence-local failure is stripped. Addendum §0 L14 is **amended for Phase 2**: "first grapheme painted ≤ 100 ms after the first sentence closes; first sentence closes ≤ 1.2 s p50 after request (measured in Task 10 with the real API)". — Buffering made the binding bar structurally unmeetable; the chunk-safe parser exists for exactly this. — Cost: a mid-reply sentence-local violation is dropped rather than regenerated (accepted; A4 says "regenerate once, then strip").
- **R5 — Task 6 adds `'@ds/brain','@ds/memory'` to `externalizeDeps.exclude` in `apps/desktop/electron.vite.config.ts` and creates placeholder `chat.html`/`key.html` with a ≤ 40-line vanilla composer** so Task 6 is verifiable alone; Task 9 replaces them with React. — Otherwise Task 6 cannot build. — Cost: ~40 throwaway lines.
- **R6 — Vitest config for apps/desktop is pre-decided:** `include: ['src/**/*.test.{ts,tsx}']`, `environmentMatchGlobs: [['src/renderer/**', 'jsdom']]`, node elsewhere; devDeps `jsdom`, `@testing-library/react`, `@testing-library/user-event`, `@testing-library/jest-dom`. **IME test = jsdom unit test** dispatching `new KeyboardEvent('keydown', {key:'Enter', isComposing:true})` on the composer (constructor-settable). The Playwright IME test is dropped; an optional CDP `Input.imeSetComposition` smoke may be added if it works in ≤ 30 min, else noted. — The plan's synthetic-event test proved nothing. — Cost: none.
