## Amendments proposed
- **A-40 §6.x second-instance rule (GC2-2).** `second-instance` is a chat request: `requestChat('second-instance', true)`, subject to the same `decideChatRequest` gate as tray/hotkey (refused under `locked`/`suspended`/`fullscreen`; user-only hide → clear `user`, apply, open). - **A-41 §5.x hidden-cancellation rule (GC2-3 / GC2-4).** `brain:state idle` for the current turn while the bubble is paused (`shell:visibility {hidden:true}`) and the turn is unfinished CANCELS the turn: timers and arm tokens invalidated, queue / sentence in flight / beat dropped, turn marked finished and inactive, band hidden, `speak()` waiters resolved, and **no** `playback:turnDone` (that ack is only ever sent for a reply someone could have seen). `speech:complete` / the band click are no-ops while paused: nothing is committed and no `playback:sentenceDone` leaves for text nobody saw; `resume()` carries the reveal on from where it stopped.
- **A-42 quit.ts step guarantee (GC2-1).** Every `before-quit` step — `teardownSync`, `drain`, `teardownAfterDrain`, `closeDb`, `quit` — is individually guarded and logged `[quit] <step> failed: <message>`; a throwing step never prevents the following ones; `phase` reaches `'done'` before `app.quit()` is attempted, and `app.quit()` is attempted exactly once per drain.
- **A-43 §6.x key-window flush (GC3-1).** `KeyRequest.onVerdict()` takes no argument: on every applied verdict it re-runs `decideKeyRequest` over the individual flags and flushes the queued reason when it returns `'open'` (so a prompt queued under `{locked,user}` opens on unlock while `user` stays set); `pending` is cleared before `show`.
- **A-44 §2.8 `storage` (A-38 follow-up).** `ErrorCode` gains `'storage'`; `ERROR_HINTS.storage = { text: '刚才那句没记住，硬盘好像写不进去', level:'warn', opensKeyWindow:false }`. Main's `persistFailed` handling: one bounded, redacted warn line; `brain:error { turnId, code:'storage', message: ERROR_HINTS.storage.text }` to the chat window (never the upstream error text); `hint:show` with the same copy to the bubble; the bubble is NOT sent `brain:error` (its handler cancels the reveal). Chat-side consumer rule to add (chat lane): `code:'storage'` is informational — do not restore the composer text or treat the turn as failed.
