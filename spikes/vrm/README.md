# VRM runtime spike

A stock VRM 1.0 humanoid rendered with three.js + `@pixiv/three-vrm` inside the same kind of window
the pet uses (transparent, frameless, always-on-top, 640x900), with the procedural layers a 3D pet
needs stacked on top: breathing, cursor look-at, blink, lip flap, expression crossfade, spring-bone
physics, a procedural wave, two-bone IK reach, a squash-and-stretch hop, VRMA clip playback and a
Mixamo FBX retarget loader. Results and honest notes: `REPORT.md`; pictures: `evidence/`.

## Run

Dependencies live in `apps/desktop` (`three@0.185.1`, `@pixiv/three-vrm@3.5.5`,
`@pixiv/three-vrm-animation@3.5.5`, installed with `pnpm add -D`). The page loads them through an
import map pointing at `../../apps/desktop/node_modules/...`, so no bundler and no network.

```
cd D:\ds\apps\desktop
npx electron ../../spikes/vrm/main.js              # interactive window, stays open
npx electron ../../spikes/vrm/main.js --capture    # scripted capture -> spikes/vrm/shots/, then exits
python ../../spikes/vrm/make_sheet.py              # contact sheets -> spikes/vrm/evidence/
cd ..\..\spikes\vrm && node --import ./test/register.mjs --test test/mixamo.test.mjs   # unit tests
```

## Interactive controls (also printed on the HUD)

| key | action |
|---|---|
| mouse move | look-at follows the cursor (eyes + head, via `vrm.lookAt`) |
| `1` `2` `3` `4` `5` | expression happy / angry / sad / relaxed / surprised (250 ms crossfade) |
| `0` | neutral |
| `B` | toggle auto blink |
| `T` | toggle lip flap (aa / ih / ou / ee / oh cycling) |
| `L` | toggle look-at |
| `I` | toggle idle breathing |
| `W` | wave (2.6 s, right arm) |
| `H` | squash-and-stretch hop |
| `N` | nudge the whole model sideways: hair/skirt spring bones react |
| `R` | IK-reach the right hand toward the cursor; `R` again releases |
| `A` | play the VRMA sample clip (`clips/test.vrma`) |
| `M` | play the Mixamo FBX (`clips/SambaDancing.fbx`) retargeted onto the VRM |
| `Space` | stop the clip (procedural layers resume) |
| `G` | toggle HUD |

`window.lab` exposes the same controls to `executeJavaScript` (`lab.expression('happy')`,
`lab.reach(x, y, z)`, `lab.play('mixamo', url)`, `lab.stats()`, ...); `main.js --capture` is the
reference script.

## Dropping in Mixamo clips

Download any Mixamo animation as **FBX Binary, "Without Skin"** (30 fps, no keyframe reduction is
fine) and put it in `spikes/vrm/anim/mixamo/`. The capture script plays every `*.fbx` it finds there
after the built-in test clip; interactively, call `lab.play('mixamo', './anim/mixamo/<file>.fbx')`.
The retarget (`lib/loadMixamoAnimation.js`, a port of three-vrm's official example) maps the 52
`mixamorig*` joints to VRM humanoid bones, bakes out the Mixamo rest rotations, and scales the hips
translation by the hips-height ratio so the clip fits a chibi as well as a 1.6 m adult.

## Layout

```
index.html        renderer: scene, VRM load, procedural layers, control surface, HUD
main.js           Electron harness (window like the pet) + capture script + perf sampling
lib/              loadMixamoAnimation.js, mixamoVRMRigMap.js (ported from three-vrm, MIT)
test/             node:test for the retarget path (no Electron, no FBX parser)
models/           VRM1_Constraint_Twist_Sample.vrm  (pixiv, VRM Public License 1.0)
clips/            test.vrma (three-vrm example, MIT repo), SambaDancing.fbx (from the three.js repo; Mixamo data - test only)
anim/             owned by the parallel "vrm-anim" agent (its own package.json); anim/mixamo/ is the FBX drop folder
shots/            raw captures + report.json (regenerated by --capture)
evidence/         sheet_motion.png, sheet_face.png
make_sheet.py     builds the sheets (checkerboard behind the alpha)
```
