# QA rubric

Critical:

- missing required part;
- transparent hole in canonical or motion envelope;
- wrong canvas registration;
- invalid PSD mode/bit depth/profile;
- duplicate imported layer name;
- identity drift in face or eyes;
- rights or provenance missing;
- accepted artifact hash mismatch.

Major:

- visible edge halo;
- insufficient overlap revealed in stress test;
- wrong draw order or clipping target;
- inconsistent lighting/line weight in hidden reconstruction;
- deformed anatomy likely to fail normal motion.

Minor:

- excess transparent padding beyond policy;
- naming clarity issue that remains unique;
- noncritical contact-sheet or report defect.

Every failure includes evidence paths, affected part IDs, reproduction command, and recommended corrective stage.
