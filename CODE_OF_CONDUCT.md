# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, be patient, assume good intent, and keep criticism about the work rather than the person.
Harassment of any kind is not tolerated, in issues, pull requests, discussions or anywhere else the project
happens.

To report a problem, use [GitHub's private reporting](https://github.com/jiaming1145/deepSeek-pet/security/advisories/new)
or contact the maintainer through GitHub. Reports are handled privately and taken seriously.
